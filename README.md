# Seaglass Store releases

This repository holds the release builds of Seaglass Store: the signed Windows installer, the program and their checksums. Installed copies check here for updates.

The source code is not published here. This repository hosts no games.

## Download

Get the latest installer from [Releases](https://github.com/ApolloF/Seaglass-Store-Releases/releases/latest).

## Report a problem

[Open an issue](https://github.com/ApolloF/Seaglass-Store-Releases/issues/new) with your Seaglass version (Settings → About), what you did and what happened. In the app, *Settings → About → Report a problem* opens the same page.
